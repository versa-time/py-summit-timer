# py-summit-timer

# Summit Timer Communication Protocol

While hard to find, the Summit Timer protocol documentation can be found here: http://www.summittiming.com/documentation_files/software_documentation/timer_protocol_and_interface/enhanced_protocol.txt

This library implements the portions of that protocol which are absolutely necessary to pull data from multiple timers and place it into modern versions of Microsoft Excel.
